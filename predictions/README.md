# Predictions written before analysis

For four analyses in the paper "Two Timescales and a Precision State: An Active-Inference Model of
Affect and Its Temporal Structure in Daily Life", the predictions and analysis plan were written down
and committed to the project's version-control history before the analysis was run. This folder
publishes those texts.

| channels_from_thought_content.md | Channels from thought content in daily life | fba8116 | 2026-10-01 15:20 -04:00 |
| vulnerability_multilevel.md | Multilevel stress reactivity and emotional inertia | 138df02 | 2026-10-01 15:20 -04:00 |

Each file gives the full hash of the original commit, its author and committer timestamps, and the
path of the file in that commit. The text under the horizontal rule is copied verbatim from that
file as it stood in that commit.

What this does and does not show. The original commits are in a private history that also contains
confidential peer-review material, so they cannot be made public, and their timestamps cannot be
checked independently from this repository. These predictions were not lodged with a public
registry. Read them as time-stamped analysis plans released at submission.

The texts are left as written. Where a detail changed after writing, the paper reports the change.
Two examples: the inertia plan cites "Koval, Kuppens, Allen and Sheeber 2012", and the paper cites the
correct source, Koval, Pe, Meers and Kuppens (2013). The vulnerability plan includes the Gainey sample;
its person-level trait file was withdrawn by openESM (release 2.0.0) and those results are not in
the paper.
